🔧 Rensa Cache

Om du får "deployment not found" fel, använd dessa verktyg för att rensa cachad data:

Manuella steg för mobil:

iPhone/Safari:

  1. Gå till Inställningar → Safari
  2. Tryck "Rensa historik och webbplatsdata"
  3. Starta om telefonen
  4. Öppna https://chockladpengar.vercel.app/

Android/Chrome:

  1. Gå till Inställningar → Appar → Chrome
  2. Tryck Lagring → Rensa lagring (inte bara cache)
  3. Starta om telefonen
  4. Öppna https://chockladpengar.vercel.app/

Om du har PWA på hemskärmen:

  1. Ta bort ikonen från hemskärmen
  2. Följ stegen ovan för att rensa cache
  3. Öppna appen i webbläsaren
  4. Lägg till på hemskärmen igen
