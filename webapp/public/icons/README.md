# PWA Icon Placeholder

Place your app icons here with these sizes:
- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

## Generate Icons

You can use an online tool like:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator

Upload a 512x512 image of your logo (chocolate coin emoji or custom design)
and it will generate all required sizes.
