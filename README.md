# 🍫 Chokladpengar

En familjemotivationsapp där barn tjänar chokladpengar genom att slutföra uppgifter, kan köpa belöningar, investera i fonder och bygga sin egen chokladfabrik!

## ✨ Funktioner

### För Barn
- 📝 **Uppgifter** - Slutför uppgifter och tjäna chokladpengar
- 🎁 **Chokladkassan** - Köp belöningar med dina chokladpengar
- 📊 **Chokladfonder** - Investera och få avkastning
- 🏭 **Chokladfabrik** - Bygg din fabrik och få passiv inkomst

### För Föräldrar
- ➕ **Skapa uppgifter** - Tilldela uppgifter till barn
- ✅ **Godkänn uppgifter** - Granska och godkänn slutförda uppgifter
- 🎁 **Skapa belöningar** - Lägg till belöningar i chokladkassan
- 👨‍👩‍👧‍👦 **Hantera familj** - Flera föräldrar kan dela samma familj

## 🚀 Kom igång

### 1. Installera dependencies

```bash
npm install
```

### 2. Kör appen

#### Android
```bash
# Starta Metro bundler
npm start

# I en annan terminal
npm run android
```

#### iOS
```bash
# Installera pods först
cd ios && pod install && cd ..

# Kör appen
npm run ios
```

## 📱 Testa på Android Studio

1. Öppna Android Studio
2. Skapa en Virtual Device (AVD)
3. Starta emulatorn
4. Kör `npm run android`

## 🎨 Design

Appen använder ett choklad-tema med custom SVG-ikoner:
- 🟤 Mörk choklad (primärfärg)
- 🟫 Mjölkchoklad (sekundär)
- 🟡 Guld (accent)

## 📦 Tekniker

- **React Native 0.73** - Mobile framework
- **TypeScript** - Type safety
- **Zustand** - State management
- **React Navigation** - Navigation
- **React Native SVG** - Custom icons
- **AsyncStorage** - Data persistence
